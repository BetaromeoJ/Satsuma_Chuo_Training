# 鹿児島県立薩摩中央高等学校 教職員ICT研修サイト

「先生の仕事がもっと楽になる｜生成AI × Google Workspace 実践講座」の研修用Webサイトです。
講師：和田 倫周（みちひろ）

## サイトの目的

このサイトは次の5つを目的としています。

1. 研修当日に講師が画面を提示しながら進行できる
2. 受講者がスマートフォンやSurface Go 2から閲覧できる
3. 研修後に操作方法やプロンプトを復習できる
4. 研修で扱った教材・サンプル・動画・リンクを一覧化できる
5. 講師である和田倫周のプロフィール、活動、著作を紹介できる

単なる資料置き場ではなく、「研修当日の体験」「研修後の継続学習」「講師の信頼性」が一体となった研修ポータルサイトを目指しています。

## ローカルでの確認方法

1. このフォルダをそのままダブルクリックせず、`index.html` を **ブラウザにドラッグ＆ドロップ** して開くか、
   お使いのPCに `python3` が入っていれば、このフォルダで次のコマンドを実行してください。

   ```
   python3 -m http.server 8000
   ```

2. ブラウザで `http://localhost:8000` を開くと確認できます。
3. 画面幅を変えたり、ブラウザの開発者ツールでスマートフォン表示に切り替えたりして、
   レスポンシブ表示を確認してください。

## GitHub Pagesでの公開方法

1. このリポジトリをGitHubにプッシュします（このフォルダがそのままリポジトリのルートになるようにしてください）。
2. GitHubのリポジトリ画面で「Settings」→「Pages」を開きます。
3. 「Branch」で公開したいブランチ（例：`main`）と `/ (root)` を選択し、保存します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
5. 画像や資料を追加した場合は、パスが相対パス（`images/...` や `assets/...`）のままになっているか確認してください。

## プロフィール写真の差し替え方法

1. 講師の写真を `images/profile/` フォルダに保存します。
2. `index.html` 内の「セクション10：講師紹介」にある次の行を探します。

   ```html
   <img src="images/profile/wada-michihiro.png" alt="講師 和田倫周の写真" ...>
   ```

3. `src` の値を、保存したファイル名に書き換えてください（例：`images/profile/wada.png`）。
4. 写真ファイルが無い場合や読み込みに失敗した場合は、自動的にイニシャル「MW」が表示されます。

## 書影の追加方法

1. 書影画像を `images/books/` フォルダに保存します（例：`images/books/canva-book-01.png`）。
2. `index.html` の「著作紹介」内、`<img src="images/books/canva-book-01.png" ...>` の
   `src` を差し替えてください。

## 著作カードの追加方法

1. `index.html` 内の「編集ここから」〜「編集ここまで」で囲まれた `.book-grid` を探します。
2. `<li class="book-card fade-in">...</li>` の1ブロックをコピーして、
   `</ul>` の直前に貼り付けます。
3. 書影、書名、著者名、出版社、発行年、内容紹介、区分（単著／共著／執筆等）、リンク先を書き換えます。
4. 著作が増えるとカードが自動的にグリッド表示され、横並び・折り返しで読みやすく表示されます。

## QRコードの差し替え方法

現時点ではQRコードの画像プレースホルダーは用意していません。QRコードを追加する場合は、
`images/icons/` フォルダに画像を保存し、掲載したいセクション（フォームやスマホリモコンなど）に
次のようなタグを追加してください。

```html
<img src="images/icons/qr-code.png" alt="QRコード（内容は後日設定）" loading="lazy">
```

## スライドやPDFの追加方法

1. スライドや配布資料を `assets/slides/` または `assets/documents/` に保存します。
2. 「セクション9：復習教材」の該当するカードのリンクを次のように書き換えます。

   ```html
   <a class="material-link" href="assets/slides/training-slides.pdf">資料を見る</a>
   ```

3. リンクを設定したら、`class="link-pending"` と `data-status="pending"` を削除してください。
   これらが付いたままだと「準備中」と表示され、リンクが無効化されます。

## YouTubeリンクの設定方法

1. 「セクション9：復習教材」の「おすすめYouTube」カードを探します。
2. `href="#"` の部分を実際の動画URLに書き換え、`class="link-pending"` と `data-status="pending"` を削除します。

## Googleフォームのリンク設定方法

1. 「セクション9：復習教材」の「Googleフォームサンプル」カードを探します。
2. `href="#"` の部分を、公開したいGoogleフォームのURLに書き換え、
   `class="link-pending"` と `data-status="pending"` を削除します。

## Canvaリンクの設定方法

現在Canvaセクションはサイト内リンク（`#canva`）で構成しています。外部のCanvaテンプレートや
実際のデザインへのリンクを追加したい場合は、該当箇所に次のようなリンクを追加してください。

```html
<a class="material-link" href="（CanvaのURL）">デザインを見る</a>
```

## プロンプトの編集方法

各プロンプトは `<pre class="prompt-text" id="...">` タグの中にそのままの文章で入っています。
文章を直接書き換えるだけで、表示とコピーの両方に反映されます。
新しいプロンプトを追加する場合は、`.prompt-card`（コピーボタン付きのカード）をコピーして、
`id` を重複しないものに変更し、`data-copy-target` の値も同じ `id` に合わせてください。

## オープニングアニメーションの有効・無効切り替え方法

- **完全に無効化したい場合**：`index.html` の `<div class="curtain" id="curtain" ...>` の
  ブロックごと削除してください（`js/main.js` 側は要素が無ければ何もしないため安全です）。
- **1回だけにしたい場合（初期設定）**：同一セッション内での再読み込みでは
  `sessionStorage` により自動的に省略されます。ブラウザタブを閉じるかセッションが切れると、
  次回アクセス時に再度表示されます。
- **常に表示したくない場合**：`js/main.js` の `initCurtain` 内で
  `sessionStorage.setItem('ictIntroShown', '1');` を、ページ読み込み時に無条件で呼び出すよう変更してください。
- 利用者のOSで「視差効果を減らす（reduce motion）」設定が有効な場合は、
  `css/style.css` の `@media (prefers-reduced-motion: reduce)` により自動的に簡略化されます。

## 色や文字サイズの変更場所

`css/style.css` の冒頭、`:root { ... }` 内の変数を編集してください。

- 背景色：`--color-bg` / `--color-bg-alt`
- メインカラー（ネイビー）：`--color-navy` / `--color-navy-deep` / `--color-navy-soft`
- アクセントカラー：`--color-accent-blue` / `--color-accent-red` / `--color-accent-yellow` / `--color-accent-green`
- 本文・見出しの文字サイズ：`--fs-base` / `--fs-lead` / `--fs-h1` / `--fs-h2` / `--fs-h3`

## 個人情報を掲載しないための注意事項

- 演習用の音声・画像・スクリーンショットには、実際の生徒名・保護者名・個人が特定できる情報を含めないでください。
- 面談記録・生徒指導記録などのサンプルは、必ず架空の内容を使用してください。
- 学校の情報セキュリティ方針や自治体のガイドラインに従い、公開してよい情報かどうかを事前に確認してください。
- 講師のプロフィールや著作情報についても、公開範囲を本人と確認したうえで掲載してください。
- GitHub Pagesは既定で誰でも閲覧できる公開ページになります。学校限定で共有したい場合は、
  公開範囲やアクセス方法（限定URL共有など）について学校の情報担当と相談してください。
